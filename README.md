Weather app

uses live API data to fetch real-time weather info using JavaScript
fetches up to date metrics including temperature, humidity, windspeed, and sunset times

##Built with 
- HTML5 and CSS3
- OpenWeatherMap API
- JavaScript

##How it works
- Starts with a default screen with a filler temperature 
- Type in any city name to get real-time weather updates
- Weather icons change depending on the weather
